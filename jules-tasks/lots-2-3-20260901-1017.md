# Terminer les Lots 2 et 3

## Objectif

Implémenter les composants restants des Lots 2 (Socle) et 3 (Formulaires) pour le design system Erebus, en React, Angular et CSS (core).

### Composants à implémenter :

**Lot 2 :**
- `IconButton` et `ButtonGroup`
- `Badge` et `Tag`
- `Avatar` et `AvatarGroup`
- `Spinner` et `Skeleton`
- `Callout`
- `Divider`, `Kbd`, et `Code`
- `Heading`, `Text`, et `Prose`

**Lot 3 :**
- `Field` et `Label`

## Instructions et Contexte
1. Lisez `AGENTS.md` à la racine pour connaître les règles du dépôt, les commandes de build et de test, et les fichiers de référence.
2. Pour chaque composant, créez l'implémentation React (dans `packages/react/src/<composant>`), l'implémentation Angular (`packages/angular/src/<composant>`), le CSS (`packages/core/src/components/<composant>.css`) et éventuellement les tokens associés si nécessaire (`packages/tokens/src/component/<composant>.json`).
3. Inspirez-vous du composant `Button` pour la structure, les tests et l'approche.
4. **Important pour Field/Label** : `Field` câble automatiquement `id`, `aria-describedby` et `aria-invalid` entre le label, la description, le message d'erreur et le contrôle.
5. Validez vos changements avec `pnpm lint`, `pnpm typecheck`, `pnpm test`, et `pnpm build` avant de finaliser.

## Contraintes
- Do not run Playwright, Cypress, or any headless-browser/e2e/UI test runner — they routinely hang or crash this sandbox and kill the session. Verify UI behavior via static/type checks and unit tests only, and describe manual verification steps in the PR description instead.
- Never run destructive git commands (`git reset --hard`, `git checkout -- .` / `git restore .`, `git clean -fd`/`-fdx`, unresolved `git stash`, force-push, history rewrite on pushed commits). Never discard uncommitted changes. Commit work incrementally and frequently so nothing is lost if the session stops early.
- Respecter l'architecture existante.
- N'ajouter aucune dépendance runtime non autorisée.
- Utiliser strictement les tokens CSS (`--erb-*`).
