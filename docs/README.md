# Documentation Erebus

Bienvenue dans la documentation officielle du Design System **Erebus**.

Erebus est conçu pour offrir une expérience unifiée, performante et accessible, supportant à la fois React et Angular.

## Structure de la documentation

- [Guide de migration depuis Bootstrap](./migration-bootstrap.md)
- [Guide de migration depuis Tailwind CSS](./migration-tailwind.md)
- [Internationalisation (i18n) et support RTL](./i18n-rtl.md)

## Principes fondamentaux

1. **Accessibilité d'abord** : Tous les composants respectent les normes WCAG.
2. **Agnostique au framework** : Styles encapsulés via CSS natif (variables `--erb-*`).
3. **Thémable** : Prise en charge native du mode sombre et clair.
